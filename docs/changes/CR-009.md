# CR-009 automatic suspend / restore

- Payment received extends `period_end`, resets data usage, restores unless another invoice is still overdue
- Time exhaustion (`period_end` + package grace) suspends and queues MikroTik disable
- Bundle exhaustion (`bundle_used_mb` ≥ `bundle_mb`) suspends immediately on RADIUS accounting
- Access policy ticks from the console (2 min) and `/api/v1/cron/billing`
- Hotspot voucher clock still terminates on expiry
