# CR-025 Customer Grace Period

Staff- and customer-granted Grace Period on top of the existing package `grace_days` / access-policy lifecycle.

- Dedicated `service_grace_periods` rows with a fixed `expires_at`. Cron cannot keep adding days.
- Grant / extend / revoke with RBAC (`services.grace.grant|extend|revoke`) and `service_grace_events` + `audit_logs`.
- `period_end` (renewal / paid-through) is never rewritten by grace. Payment still uses `grantPaidPeriod`.
- ISP eligibility terms in `grace_policies` (Settings → Grace period). Eligible customers can add grace from `/portal`.
- RADIUS session timeout uses `max(period_end + package.grace_days, grant.expires_at)`.
- Reports list current grants, days, staff usage, and suspensions after grace. Grace lines are not counted as paid-active.
