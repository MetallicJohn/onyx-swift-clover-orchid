# CR-011 FreeRADIUS REST adapter

- `POST /api/v1/radius/{authorize|authenticate|accounting}/{slug}` speaks rlm_rest JSON
- Per-tenant RADIUS API key, sealed at rest, rotated from the RADIUS console
- Authorize returns Cleartext-Password + MikroTik rate-limit; suspended / expired / FUP reject
- Accounting understands nested AVPs, gigawords, and Stop
- Console copies REST module, site, clients.conf, MikroTik `/radius` snippet
- Daemon stays external
