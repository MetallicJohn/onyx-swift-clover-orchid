# CR-014 invoice and statement PDFs

Server-side A4 PDFs (pdfkit), not HTML print or screenshots.

- Tenant branding from `tenants` + enabled `payment_providers` (name, address, colour, PIN, bank, paybill/till). No hardcoded ISP name.
- Invoice: bill-to, package/period lines, exclusive VAT, previous balance, receipts, amount due or credit balance, status chip.
- Statement: chronological ledger with running balance, summary cards, credit vs outstanding.
- Actions: view / download / print / email from Billing, Statements, and the customer portal. Email uses the existing outbox (Resend when keyed; otherwise queued with the PDF attached in the send payload).
- Settings → Company: address, website, PIN, colour, bank, footer, notes.
