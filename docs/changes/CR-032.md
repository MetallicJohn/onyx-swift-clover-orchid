# CR-032 Safer VPS deploy

Production must not update from Grok or from an untested branch.

```
GitHub push → CI checks → backup → VPS pull → migrate → health → rollback
```

- `update.sh --apply` / `--from-ci` backs up Postgres, pulls `main`, rebuilds, waits for `/api/v1/health`, rolls the previous SHA back if health fails.
- Systemd timer still fetches `origin/main` every 5 minutes but **does not rebuild** unless `ISPSOLUTIONS_AUTO_DEPLOY=1`.
- GitHub `publish-vps` still requires green `checks` on `main`. Secrets: `VPS_HOST`, `VPS_SSH_KEY`; optional `VPS_USER`, `VPS_PATH`, `VPS_HEALTH_URL`. Missing secrets skip SSH (tests still run).
- CI SSH timeout is 20 minutes so backup + image build can finish.

See [docs/deployment.md](../deployment.md).
