# CR-016 WireGuard hub server config

Hub-and-spoke overlay was keys-only. This adds the missing **server** configuration.

- Per-ISP hub keypair + public endpoint (`tenants.wg_*`)
- `wg-gridline.conf` (Address, ListenPort, PrivateKey, one `[Peer]` per router)
- VPS install script (`wg-quick up wg-gridline`)
- Enroll `.rsc` now sets the router private key, hub public key, and `endpoint-address`/`endpoint-port`
- `wireguard_peers` is written on enroll
- Settings → Network; Routers shows overlay IP and warns if the hub endpoint is missing

Kernel handshake on a real NIC is still not run in CI.
