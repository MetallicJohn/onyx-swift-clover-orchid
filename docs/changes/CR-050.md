# CR-050 dd/mm/yy date entry

Default date format is **dd/mm/yy** for display and for date fields. Storage stays `YYYY-MM-DD`.

| Surface | Behaviour |
|---|---|
| Default | `tenants.date_format` and `DEFAULT_DATE_FORMAT` are `dd/mm/yy` (16/09/26). |
| Customer / service create | Subscription start and expiry on Add Customer / Add Service are typed as dd/mm/yy. |
| Service expiry | Staff expiry editor uses the same field. Preview still shows the console format. |
| Other date fields | Invoice due date, maintenance date, recycle-bin and payment/report range filters use the same control. |
| Import | CSV still accepts `dd/mm/yy` and `YYYY-MM-DD` (`parseFlexibleYmd` → `parseYmdInput`). |

Native HTML `type="date"` pickers are not shown. A calendar button remains as an optional picker; the visible value is the console format. Tenant settings can still choose another display format; date fields follow it. Default remains dd/mm/yy.

Proof: `display.test.ts`, `onboard.test.ts`, `onboard-import.test.ts`.
