# CR-012 customer churn score

Interpretable logistic model on live ISP signals (not a trained neural net, no labelled history in this product).

Features: service status, overdue days, outstanding vs ARPU, last payment age, grace/FUP, period ending unpaid, open and billing tickets.

- Score 0–100, bands low / medium / high / churned
- Reasons shown next to the score
- Overview: at-risk list + counts
- Customers: column + At risk filter
