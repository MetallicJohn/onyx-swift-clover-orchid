# CR-008 production proofs, RLS, CI

## What changed

- PostgreSQL RLS (`ENABLE` + `FORCE`) on every tenant-owned table except membership lookup tables
- `gridline` non-superuser role for tests; app sets `app.tenant_id` / `app.bypass_rls`
- Removed the published `gridline-dev-secret-change-me` fallback. Production or any `DATABASE_URL` requires `APP_SECRET` / `BETTER_AUTH_SECRET`
- Integration proofs: tenant isolation, M-Pesa idempotency + amount mismatch, ledger zero-balance after pay, WireGuard X25519 ECDH, agent enroll/approve/audit, grace then suspend then restore
- `npm run test:db` applies every migration on a clean database
- `npm run test:pg` (CI) re-runs domain proofs against a throwaway Postgres 16 database
- GitHub Actions: typecheck, lint (`--max-warnings 0`), auth invariant, tests, migrations, Postgres proofs
