# CR-034 Customer lifetime value on Insights

Tenant Insights (`/app/reports`) now has a **Lifetime value** tab. Figures come from the live tenant book:

| Metric | Source |
|---|---|
| This-month ARPU | Confirmed collections this month / active customers |
| List ARPU | Average monthly package price of customers on a live service |
| Predicted CLV | This-month ARPU ÷ monthly churn (same churn as the Retention tab) |
| Expected tenure | 1 / monthly churn |
| Average / median realized LTV | Confirmed collections per paying customer (historic, including leavers) |
| Gross margin & CAC | **Not collected** — never invented |

By-package rows use list price ÷ tenant churn. Highest realized LTV is historic collected, not a forecast.

See `src/lib/isp/clv.ts`. Proven in `clv.test.ts`.
