# CR-024 Superadmin / SaaS Management Console

Dedicated `/platform` surface for `platform_admins`. Tenant RBAC is unchanged. Superadmin uses an explicit RLS bypass after a server-side admin check — never a client-sent tenant id.

- Database-driven `saas_plans` + feature entitlements; Trial/Starter/Growth/Professional/Enterprise seeded.
- Subscription lifecycle: trial, active, past_due, grace, suspended, cancelled, expired. Suspend/cancel does not delete ISP data.
- Platform audit log, settings, infra node telemetry (`POST /api/platform/telemetry`), optional time-limited support access (off by default).
- ISP console keeps its own nav and tenant theme; Superadmin chrome stays ISP Solutions branding.
