# CR-022 Tenant appearance / white-label themes

Per-ISP palettes, logo, favicon, light/dark, and display name. Stored on `tenants` (`0024_tenant_theme.sql`). Console, portal, optional `?isp=` login, and invoice PDFs use the active tenant only. Platform landing stays ISP Solutions. Status colours stay semantic.

- Settings → Appearance: 12 presets, custom hex, live preview of the whole console, logo/favicon, display name, login/portal branding flags.
- CSS tokens (`--color-*` plus `--primary` / `--sidebar` / `--header` / `--chart`) applied at runtime; no second design system.
- Save is owner/admin only (`settings.manage`). Server resolves the active tenant; the browser never supplies a tenant id.
- Invoice `brand_color` follows the resolved Appearance primary (preset or custom).
