# CR-020 Paybill / till incoming payments

Every C2B hit on the paybill or till is stored, including unknown bill references. Auto-match uses account number, invoice number, username, or phone. Unmatched rows sit on Reports → Paybill / Till for finance to select and assign to a customer (optional invoice). STK with a known intent is not auto-matched (would double-credit). Amount-mismatched STK is parked unmatched. Duplicate TransID is idempotent. C2B always returns ResultCode 0 so Safaricom never retries a rejection.
