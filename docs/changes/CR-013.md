# CR-013 password reset

ISP login and ISP Solutions superadmin share Better Auth email/password. Reset is our token table (hashed, 30 minutes, single use), not a Better Auth plugin — `src/lib/auth/server.ts` stays frozen.

- `/reset-password` request + complete. No SMTP → the link is shown in-app; Resend sends when `RESEND_API_KEY` is set.
- Superadmin can set any operator password. ISP owners can reset staff from Settings.
- Signed-in operators change their own password in Settings (current password required; session stays).
- Customer portal: optional password, SMS-code reset, staff can set a portal password on the customer.
- Portal customers change their password while signed in.

Sessions are revoked when an admin or forgot-password flow changes an operator password.
