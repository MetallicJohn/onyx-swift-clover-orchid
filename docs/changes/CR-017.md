# CR-017 VPS publish

Self-host pack under `deploy/vps/`:

- Dockerfile builds Nitro `node-server` (Grok/Vercel still uses the `vercel` preset)
- Compose: Caddy + Postgres 16 + web
- `install.sh` for Ubuntu 24.04 (Docker, firewall, secrets, WireGuard tools)
- Settings → Network → Publish to a VPS shows the install command from the tenant public URL

Secrets live in `/opt/gridline/gridline.env` on the server. No `.env` is committed.
