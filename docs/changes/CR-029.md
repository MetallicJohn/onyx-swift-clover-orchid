# CR-029 ISP Solutions naming

Replace the previous internal product id with ISP Solutions everywhere operators see: install path `/opt/ispsolutions`, env file `ispsolutions.env`, Compose project `ispsolutions`, Postgres role/user/db defaults, GenieACS extension `ispsolutions`, systemd timer `ispsolutions-update`, and `ISPSOLUTIONS_*` environment keys.

- Existing VPS checkouts at `/opt/gridline` and `gridline.env` are still detected and migrated on update.
- Existing Docker volume `gridline_pgdata` keeps the previous Compose project name so data is not orphaned.
- MikroTik enroll/hub scripts still rename a previous overlay to `wg-ispsolutions`.
