# CR-026 PCQ package profiles

Switch bandwidth provisioning from per-session simple queues to PCQ per package.

- RADIUS Access-Accept sends `Mikrotik-Group` = `isp-{package}` and no longer sends `Mikrotik-Rate-Limit`.
- Agent creates one PCQ upload type (classifier `src-address`) and one download type (`dst-address`) per speed, plus matching PPP/hotspot profiles.
- Static customers are placed on the package address-list; mangle + queue tree shape the package. Per-IP `/queue simple` is removed.
- Saving a package queues `package.sync` on every enrolled router.
