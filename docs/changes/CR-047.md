# CR-047 TR-069 service auto-provision

Assigned CPE/ONU devices receive WAN PPPoE, SSID, and Wi-Fi password from the billed service on Inform. ISP Solutions still does not speak TR-069; GenieACS runs the `ispsolutions-service` provision.

| Surface | Behaviour |
|---|---|
| Inform rule | Reads ACS username + serial, looks up the assigned service. Writes PPPoE WAN (TR-098 and TR-181) only for PPPoE services with RADIUS credentials. Writes SSID and WPA2 password on 2.4/5 GHz paths when those values exist. Empty fields are not written. Unassigned or unknown devices are skipped. |
| Service fields | `wifi_ssid` and sealed `wifi_password_ref`. Generated from the customer name + account if empty when the service is created (PPPoE/static) or when a device is assigned. Staff Wi-Fi on the device desk updates the same service so the next Inform stays in sync. |
| Platform | **Provision WAN, SSID, and Wi-Fi password from the assigned service on inform** (default on). Saving ACS platform settings or testing the ACS connection pushes the provision/preset. Turning it off removes the preset. |
| Not changed | URL lock, digest auth, OLT snippets, firmware, STUN/XMPP, billing, SMS. Live CPE session is not run in CI. |

Proof: `acs-service-provision.test.ts`, `acs-security.test.ts`.
