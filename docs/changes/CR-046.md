# CR-046 Superadmin infrastructure card

The SaaS overview Infrastructure card now binds to authenticated `infra_nodes` heartbeats. CPU, RAM, and disk percentages are last-reported values. vCPU count and used/total bytes are not stored today, so the card shows **Not available** instead of invented capacity. Missing telemetry shows **Infrastructure data unavailable**. Stale heartbeats (older than 10 minutes) keep last metrics and are marked stale. Service counts come from `postgres_ok` / `redis_ok` / `genieacs_ok` on those nodes. Tenant operators cannot load the overview.

Proof: `platform.test.ts`, `display.test.ts`.
