# CR-027 TR-069 security

CPE → ACS digest authentication, optional HTTPS ACS URLs, and ACS URL lock on the existing GenieACS sidecar.

- Each ISP’s ONUs must present that ISP’s ACS username and password. GenieACS `cwmp.auth` uses `AUTH(USERNAME, EXT("gridline", "passwordFor", USERNAME))`; the extension looks up the sealed secret over the private `/api/internal/acs-auth` endpoint.
- Connection-request login stays distinct from ACS login. `cwmp.connectionRequestAuth = AUTH(username, password)` uses the values written onto the CPE.
- Platform `acs_tls` is `http` (default) or `https`. Existing OLT profiles keep working until a superadmin switches the scheme and updates the OLT. Optional TLS on the TR-069 edge via `ACS_TLS_CERT` / `ACS_TLS_KEY`.
- When `acs_lock_url` is on, a GenieACS preset writes this ISP’s ACS URL (and connection-request credentials) back onto the ONU on inform so it cannot be redirected.
- NBI, Mongo, and the auth endpoint stay off the public internet. Informs are not written to `audit_logs`.
