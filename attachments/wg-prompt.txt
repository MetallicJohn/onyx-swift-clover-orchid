# ISP SOLUTIONS — PRODUCTION IMPLEMENTATION PROMPT

## MikroTik RouterOS v7 Agent, WireGuard Management Plane, Certificate-Free Enrollment & Router Provisioning

You are implementing the production MikroTik integration for **ISP Solutions**, a multi-tenant ISP management SaaS.

This implementation must be production-ready, secure, idempotent, observable, backward-compatible, and deployable on the existing VPS architecture.

Do not provide a conceptual prototype. Implement the complete functionality in the existing repository while preserving existing working functionality.

# 2. MIKROTIK CERTIFICATE REQUIREMENT

## ABSOLUTE REQUIREMENT

The MikroTik integration must NOT depend on the MikroTik certificate store.

Do NOT require users to:

* install a CA certificate
* import a CA
* trust a custom CA
* configure RouterOS certificates
* enable API-SSL because of certificate requirements
* use `check-certificate=yes`

All RouterOS bootstrap and persistent HTTPS agent requests must use:

```routeros
check-certificate=no
```

The WireGuard tunnel is the trusted management channel.

Do not later "improve security" by introducing certificate requirements.

The implementation must explicitly preserve this architecture.
